# GalaAi2.0

ERP für Garten- und Landschaftsbau: Kunden, Objekte und Projekte, Kalkulation
mit Rezepturen, Angebote und Rechnungen (PDF/A, XRechnung, ZUGFeRD), Zahlungen,
Mahnwesen, Bankabgleich, DATEV-Export, Zeiterfassung und Dokumente mit
Texterkennung. Backend NestJS + Prisma + PostgreSQL, Frontend React + Vite.
