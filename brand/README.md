# gAla – Garten Landschaft Bau App

Markenzeichen für das Neudesign (Variante „C2 – kräftiger“: das **l** ist oben und unten
gegenläufig geschwungen, das **A** trägt Pflastersteine). Eingebaut wird es erst mit dem
Neudesign; bis dahin nutzt die App weiter das bisherige GartenAI-Erscheinungsbild.

| Datei | Inhalt |
|---|---|
| `gala-logo.svg` / `.png` | Bildmarke, Schriftzug und Zusatz „Garten Landschaft Bau App“ auf Weiß |
| `gala-logo-transparent.svg` | dasselbe ohne Hintergrund |
| `gala-wordmark.svg` / `.png` | nur der Schriftzug „gAla“ (Kopfzeile, Rechnungen) |
| `gala-mark.svg` / `.png` | nur die Bildmarke (App-Symbol, Favicon) |

## Farben

| Name | Wert | Verwendung |
|---|---|---|
| Tannengrün | `#1f4a2e` | Schrift, Rahmen, Baum |
| Rasengrün | `#6c9a3c` | „A“, Rasen, Gräser |
| Pflastergrau | `#6e6e6e` | Pflastersteine, Mauer |

Die Zusatzzeile ist als Text gesetzt (Systemschrift). Für den Druck sollte sie vorher in Pfade
umgewandelt werden, damit die Schrift überall gleich aussieht.
